# Java-Swing-Course

## 📚 Giới thiệu
Khoá học này tập trung vào **Java Swing** – thư viện GUI của Java dùng để xây dựng ứng dụng desktop.  
Toàn bộ ví dụ và bài tập được viết thủ công bằng **Visual Studio Code (VS Code)**, không sử dụng kéo-thả giao diện.

## 📂 Nội dung khoá học
Các thư mục trong repo được sắp xếp theo từng chủ đề:
- **JFrame**: Cửa sổ chính của ứng dụng
- **JPanel**: Vùng chứa các thành phần
- **JTextFieldd / JTextTareaa**: Ô nhập văn bản
- **JOptionpane**: Hộp thoại thông báo
- **JRadioJcheckBox**: Radio button và checkbox
- **JComboboxJList**: Danh sách chọn
- **MENU**: Thanh menu
- **ImageIcon / Font / Color**: Tuỳ chỉnh giao diện
- **mouse**: Xử lý sự kiện chuột
- **MVC**: Mô hình thiết kế Model-View-Controller
- **QLSV**: Ứng dụng quản lý sinh viên (ví dụ nâng cao)
- **VeHinh**: Vẽ hình cơ bản với Swing
